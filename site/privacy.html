BeatNext 0.1

Privacy

BeatNext has no account system, sign-in, telemetry, analytics, advertising, cookies, crash upload, or project-operated backend.

Network requests

The headset sends anonymous search and radio requests directly to YouTube Music. It sends map metadata and download requests directly to BeatSaver. Those services receive normal network information such as the headset's IP address.

Local data

BeatNext stores two settings, bounded anonymous response caches, and temporary staged downloads in its Quest mod-data directory. Deleting that directory removes this data. Downloaded custom songs remain managed separately by SongCore.

Open source

The source code, issue tracker, and release history are available in the BeatNext repository.
