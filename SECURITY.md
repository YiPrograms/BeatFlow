# Security policy

## Supported version

Only the current unreleased `0.1.x` development line receives security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for the BeatFlow repository. Do not open a public
issue for a flaw that could expose OAuth credentials or tokens, escape the map staging directory,
install an unsafe archive, or execute untrusted data.

Include the affected revision, reproduction steps, impact, and a proposed fix if you have one. Never
attach real account credentials, tokens, cookies, authorization codes, or an unsanitized personalized
response. Maintainers will acknowledge a complete report, coordinate a fix, and credit the reporter if
requested.
